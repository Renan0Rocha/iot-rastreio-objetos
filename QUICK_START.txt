🔧 PASSO 1: CONFIGURAR URL DA API

Edite config.json e ajuste a URL:

  {
    "api": {
      "url": "http://SEU_SERVIDOR:PORTA/api/rfid"
            ⬆️ ALTERE AQUI
    }
  }

Exemplos:
  • Local:  http://localhost:3000/api/rfid
  • Remoto: https://api.exemplo.com/v1/rfid

🚀 PASSO 2: EXECUTAR

┌─────────────────────────────────────────┐
│ Terminal 1: Upload para Arduino         │
└─────────────────────────────────────────┘

  ~/.platformio/penv/bin/platformio run --target upload

┌─────────────────────────────────────────┐
│ Terminal 2: Iniciar Bridge Python       │
└─────────────────────────────────────────┘

  python3 rfid_bridge.py

✅ Sistema operacional! Aproxime tags dos leitores.

📤 DADOS ENVIADOS PARA SUA API (HTTP POST):

{
  "reader": "Leitor_1",              ← Qual leitor detectou
  "uid_hex": "7F:BE:A3:FB",          ← UID hexadecimal
  "uid_decimal": 2143200251,         ← UID decimal
  "card_type": "MIFARE 1KB",         ← Tipo do cartão
  "date": "2025-11-17",              ← Data
  "time": "14:35:22",                ← Hora
  "datetime": "2025-11-17T14:35:22", ← ISO 8601
  "timestamp_ms": 1700234122000      ← Unix timestamp
}

📍 CONEXÕES FÍSICAS (Lembre-se):

  Leitor 1: SDA→D10, RST→D9
  Leitor 2: SDA→D8,  RST→D7
  
  Compartilhados: MOSI→D11, MISO→D12, SCK→D13, 3.3V, GND

💡 DÚVIDAS?
  • Erro de conexão API: Verifique URL em config.json
  • Leitor não detecta: Verifique conexões SDA e RST
  • Porta serial: Ajuste em config.json ("port")
